# 图片转 ICO

一个 Windows 免安装的图片转图标工具：拖几张图进去，选好尺寸和圆角，一键生成 `.ico`。

- 单文件 exe，无需安装，可放 U 盘或任意目录
- 支持 PNG / JPG / JPEG / BMP / GIF / ICO / WEBP / TIFF
- 目标尺寸可选 16 / 24 / 32 / 48 / 64 / 128 / 256，任意组合
- 圆角半径 0–50%，适用于做圆角应用图标的场景
- 多个尺寸打包进同一个 .ico（小尺寸用 BMP 帧，128/256 用 PNG 帧）
- 支持拖放整个文件夹、批量转换、保留透明通道

## 使用

1. 下载 `图片转ICO.exe`（见 Releases）
2. 双击运行，把图片拖进窗口，或点击选择文件
3. 勾选需要的尺寸，设置圆角半径
4. 选择输出位置（默认生成在图片旁边）
5. 点「生成 ICO 图标」

## 命令行

```
图片转ICO.exe --convert <输入图片> [输出.ico] [--sizes 16,32,256] [--radius 15]
```

不传输出路径时，默认在同一目录生成同名 `.ico`。

## 构建

需要 Windows 自带的 .NET Framework 4.x 编译器：

```
build.bat
```

产物在 `dist\app.exe`，可自行改名为 `图片转ICO.exe`。

## 说明

- 单张图片上限 100 MB；内存占用约为「宽 × 高 × 4 字节」，特别大的图可能加载失败
- WebP 依赖系统的 WebP 图像扩展（Win10/11 一般已预装）
